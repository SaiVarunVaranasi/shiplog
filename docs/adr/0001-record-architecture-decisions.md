# 1. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-10-18

## Context
Design decisions in this project need to be traceable: why something was chosen, and which alternatives were rejected.

## Decision
Record significant decisions as Architecture Decision Records in `docs/adr/`, using the format: Context, Decision, Consequences. ADRs are numbered sequentially and never deleted; a reversed decision gets a new ADR that supersedes the old one.

## Consequences
- Decisions are reviewable in pull requests like code.
- New decisions require a short write-up before implementation.
